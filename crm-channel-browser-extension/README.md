# 企微渠道采集器

这是一个供内部测试使用的 Chrome/Edge Manifest V3 插件。它复用当前浏览器中的企微文档登录状态，捕获智能表格导出的 Excel 文件，并上传到 CRM 渠道来源导入接口。

## 当前能力

- 内置两张企微智能表格，可在设置页增删或修改。
- 支持手动同步当前表格。
- 支持同步全部已启用表格。
- 支持每天配置两个自动执行时间。
- 优先从页面的 `fetch`、`XMLHttpRequest` 和 `Blob` 中捕获导出文件。
- 页面捕获失败时，尝试从浏览器下载记录中再次读取文件。
- 文件内容 Hash 未变化时跳过导入。
- CRM 按渠道来源和记录身份指纹再次去重。
- 插件展示最近同步结果和失败原因。

## 安装

1. 打开 Chrome 的 `chrome://extensions`，或者 Edge 的 `edge://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择当前 `crm-channel-browser-extension` 目录。
5. 建议把插件固定到浏览器工具栏。

## 第一次测试

### 1. 绑定 CRM 登录

1. 在浏览器中打开并登录 CRM。
2. 保持当前页面为 CRM 页面，点击插件图标。
3. 点击“绑定当前CRM登录”。
4. 浏览器会询问是否允许插件访问当前 CRM 地址，选择允许。

插件只读取 CRM 保存到当前页面 `localStorage` 中的 `crm.token`，不读取用户名和密码。

### 2. 确认 CRM 接口

1. 打开插件设置页。
2. 确认 CRM 地址正确。
3. 默认上传接口为 `/api/channel/source/import-excel`。
4. 点击“测试CRM连接”。

对应后端需要包含本次新增的渠道 Excel 导入接口，并且登录用户拥有以下任一权限：

- 全部权限 `*`
- `crm:wecom:sync`
- `crm:channel:manage`

### 3. 先测试手动捕获

1. 使用同一个浏览器打开企微智能表格并完成登录。
2. 点击插件图标。
3. 点击“检测当前表格”，确认页面可被插件识别。
4. 点击“学习一次手动导出”。
5. 在两分钟内从企微页面手动完成一次 Excel 导出。
6. 插件捕获文件成功后，会保存本次菜单点击路径，后续自动同步优先复用该路径。

同一套企微智能表格界面会共用最近一次成功学习的导出路径；如果某张表单独学习过，则优先使用该表自己的路径。
6. 查看插件“最近同步”记录。

建议先做这一步，因为它可以单独验证腾讯当前版本的导出文件能否被插件捕获。

### 4. 测试自动导出

1. 停留在企微智能表格页面。
2. 点击“自动同步当前表格”。
3. 插件优先复用已经学习的导出路径；没有学习记录时，再尝试寻找“更多/文件 → 导出 → Excel”等入口。

如果最近同步中出现“没有找到导出入口”，请先在扩展管理页重新加载插件并刷新企微表格页面，然后执行一次“学习一次手动导出”。捕获成功后，可点击“检测当前表格”确认页面已经记录导出路径，再测试自动同步。
4. 如果页面按钮名称发生变化，插件会提示改用手动捕获。

### 5. 开启每天两次同步

1. 在设置页开启“自动同步”。
2. 设置两个执行时间。
3. 保存设置。
4. 保持浏览器运行，确保当前浏览器账号仍能打开两张智能表格。

电脑关机、休眠或浏览器完全退出时，浏览器插件无法执行定时任务。

## CRM 数据处理

插件上传表格原始 Excel，不在浏览器中解释或修改客户数据。CRM 后端完成：

1. 自动识别前二十行中的真实表头。
2. 提取联系人、公司名称、联系电话和邮箱。
3. 保存完整原始行数据快照。
4. 优先按手机号，其次按邮箱，再按公司和联系人生成身份指纹。
5. 相同身份且内容未变化时跳过。
6. 相同身份但内容变化时更新尚未晋升线索的渠道记录。
7. 生成渠道来源同步日志。

删除企微表格中的记录不会自动删除 CRM 数据。

## 已知限制

- 这是基于真实页面导出动作的适配器，不是企业微信官方数据读取接口。
- 企微页面改版后，自动点击规则可能需要调整。
- 如果腾讯通过浏览器私有下载机制生成文件，纯插件可能只能检测到下载完成，无法再次读取文件内容。
- 登录过期、扫码确认或验证码出现时，需要人工重新登录。
- 当前仅支持 Excel 的 `xlsx` 和 `xls` 格式。
- 首版单个文件限制为 20MB，单次最多导入 10000 行。

如果手动捕获能够成功，而自动点击失败，只需要根据实际页面调整 `content.js` 中的导出入口匹配规则，不需要改变后端导入链路。
