# 企业微信客户主动同步设计

## 一、适用场景

CRM 部署在内网，但服务器可以主动访问企业微信接口。系统不依赖公网回调，按照配置的时间间隔主动拉取外部联系人和客户群。

主流程如下：

1. 管理员在“渠道管理—企业微信同步”中填写企业 ID 和客户联系 Secret。
2. 系统获取有客户联系权限的企业微信员工。
3. 分页拉取员工添加的外部联系人。
4. 拉取这些员工负责的客户群及群成员。
5. 将企业微信原始资料保存到独立同步表。
6. 按企业 ID 与外部联系人 ID 幂等写入渠道池。
7. 渠道记录进入渠道池，可以直接晋升线索。
8. 销售也可以先通过渠道智能体补充分析备注，再决定是否晋升。

## 二、企业微信侧准备

需要在企业微信管理后台准备：

- 企业 ID；
- “客户联系”应用 Secret；
- 将需要同步客户的员工加入应用可见范围；
- 确保这些员工拥有客户联系权限；
- CRM 服务器能够通过 HTTPS 访问 `qyapi.weixin.qq.com`。

Secret 只在保存时接收，查询接口不会返回明文。运行日志禁止输出 Secret 和访问令牌。

## 三、重复数据控制

系统使用三层防重：

1. 同一企业配置已有 `PENDING` 或 `RUNNING` 任务时，人工点击和定时扫描直接复用当前任务。
2. 每个企业配置使用 Redisson 分布式锁，同一时间只有一个实例可以执行同步。
3. PostgreSQL 唯一约束作为最终兜底。

关键唯一键：

| 数据 | 唯一键 |
| --- | --- |
| 外部联系人 | `tenant_id + config_id + external_user_id` |
| 好友关系 | `tenant_id + config_id + external_user_id + wecom_user_id` |
| 客户群 | `tenant_id + config_id + chat_id` |
| 客户群成员 | `tenant_id + config_id + chat_id + member_user_id` |
| 渠道记录 | `tenant_id + external_provider + external_key` |

渠道的 `external_key` 使用 `corpId:externalUserId`。同步内容会生成 SHA-256 版本摘要；摘要没有变化时不更新渠道、不清空已有 AI 结果，只累计“重复跳过”统计。

## 四、负责人分配

首次同步会发现企业微信员工账号，并显示在员工映射区：

- 已映射：客户自动分给对应 CRM 用户；
- 未映射但配置默认负责人：分给默认负责人；
- 两者都没有：负责人留空，进入公共渠道池等待管理员分配。

员工映射和默认负责人都必须由管理员明确配置，系统不按姓名猜测关联关系。

## 五、数据库变更

JPA 实体负责创建新增表和新增字段。历史 `crm_channel_record` 表的枚举检查约束不会由应用兼容处理，升级已有数据库前由开发人员手动执行：

`deploy/sql/manual/20260730-wecom-channel-type.sql`

该脚本只更新渠道类型检查约束，使 `WECOM` 成为合法渠道类型。执行前应备份数据库并确认当前约束名称。

## 六、运行配置

部署环境变量：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `CRM_WECOM_BASE_URL` | `https://qyapi.weixin.qq.com` | 企业微信接口地址 |
| `CRM_WECOM_CONNECT_TIMEOUT_MS` | `5000` | 连接超时 |
| `CRM_WECOM_READ_TIMEOUT_MS` | `30000` | 读取超时 |
| `CRM_WECOM_SCHEDULE_DELAY_MS` | `60000` | 调度扫描间隔 |
| `CRM_WECOM_SCHEDULE_INITIAL_DELAY_MS` | `30000` | 首次扫描延迟 |

Redis 必须启用，用于访问令牌缓存、任务提交锁和同步执行锁。

## 七、验收建议

1. 首次同步后检查外部联系人、客户群、成员和渠道数量。
2. 不修改企业微信数据，再执行一次同步，确认渠道新增数量为零且重复跳过数量增加。
3. 修改客户备注或让客户加入新群，再同步，确认原渠道被更新且没有新增重复渠道。
4. 同时点击两次“立即同步”，确认只返回一个进行中的任务。
5. 使用两个应用实例同时触发，确认数据库中没有重复联系人和重复渠道。
6. 完成渠道 AI 整理后晋升线索，确认同一企业微信客户只产生一个渠道来源。
