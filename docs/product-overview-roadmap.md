# 智能营销管理系统产品说明与迭代计划

## 一、产品定位

智能营销管理系统是一套从传统 CRM 演进到 AI CRM 的企业级营销与销售管理平台。产品目标不是简单替代现有 CRM 表单，而是围绕“渠道获客、线索识别、客户经营、商机推进、销售协同、AI 分析”形成完整闭环，让企业从被动记录客户信息，升级为主动发现机会、判断优先级、辅助销售决策的智能业务系统。

系统坚持接入真实业务数据，不使用伪造数据填充业务结果。当前没有真实数据时，页面展示空状态和待接入提示，避免管理层和业务团队被演示数据误导。

## 二、目标用户与业务价值

### 目标用户

- 企业老板、销售负责人：查看客户资产、渠道效果、销售推进情况和业务风险。
- 销售团队：管理线索、客户、商机、跟进记录和销售任务。
- 市场团队：管理渠道来源、活动线索、录音/视频素材和营销转化效果。
- 管理员：管理组织、角色、菜单权限、数据权限、模型配置和系统参数。

### 核心价值

- 提高线索转化效率：从渠道数据、录音、视频、文本资料中提取有效线索。
- 提升客户经营质量：沉淀客户资料、跟进记录、需求、风险和决策链信息。
- 降低销售管理成本：通过角色、菜单权限、数据权限控制团队协作边界。
- 形成 AI 辅助决策能力：基于真实客户数据生成摘要、洞察、风险提示和下一步建议。
- 支持企业级部署：具备初始化安装、超级管理员、租户根部门、日志、Redis 会话和后续扩展能力。

## 三、产品核心模块

### 1. 系统初始化与基础设置

- 首次安装时检测是否存在超级管理员。
- 没有超级管理员时进入初始化页面，设置超级管理员用户名和密码。
- 初始化租户同时作为默认顶级部门。
- 系统只允许一个超级管理员，超级管理员角色由系统维护。
- 支持系统 Logo 自定义、主题适配、开发/生产环境配置。

### 2. 组织与权限管理

权限体系分为两类：

- 菜单权限：控制用户能看到哪些系统菜单和功能入口。
- 数据权限：控制用户能访问哪些业务数据，例如全部数据、部门及下级数据、部门数据、本人数据。

管理能力包括：

- 部门管理。
- 用户管理。
- 角色管理。
- 菜单权限管理。
- 数据权限管理。
- 按模块勾选权限，降低配置复杂度。
- 权限编码、菜单编码由后台自动生成，避免人工填写错误。

### 3. 渠道管理

渠道管理是从市场触点到线索转化的入口模块。

当前规划能力：

- 手动新增渠道记录。
- 导入录音或视频资料。
- 为后续中文转译预留处理入口。
- 为后续 AI 分析预留处理入口。
- 渠道记录可晋升为销售线索。
- 记录渠道来源、联系人、公司、电话、邮箱、备注、媒体文件信息和处理状态。

后续目标是让市场活动、电话录音、会议视频、直播回放等非结构化素材自动进入线索池，减少人工整理成本。

### 4. 线索管理

线索管理用于承接渠道转化结果，并进入销售跟进流程。

规划能力：

- 线索列表、详情、新增、编辑。
- 线索来源、联系人、公司、联系方式、状态管理。
- 支持由渠道记录自动晋升线索。
- 后续接入 AI 评分、意向判断、重复线索识别和跟进建议。

### 5. 客户管理

客户管理是客户资产沉淀中心，先以真实客户列表为入口，再进入客户详情。

当前规划能力：

- 客户列表查询。
- 客户详情查看。
- 客户新增、编辑、删除。
- 支持客户名称、行业、联系人、电话、邮箱搜索。
- 按数据权限控制客户可见范围。
- 暂无 AI 结果时展示待接入状态，不展示伪造分析。

后续会围绕客户画像、决策链、跟进历史、商机统计、风险提示和 AI 总结展开。

### 6. 商机管理

商机管理用于承接客户成交过程。

规划能力：

- 商机列表与详情。
- 商机阶段管理。
- 金额、赢单率、预计成交时间管理。
- 后续支持看板视图、阶段推进、风险预警和预测成交。

### 7. 大模型配置管理

系统需要支持企业配置自己的模型服务。

规划能力：

- 大模型供应商配置。
- 模型名称、接口地址、密钥、启用状态管理。
- 模型可用性检测。
- 为不同 AI 场景配置不同模型。
- 后续支持调用日志、成本统计、失败重试和模型降级。

### 8. Agent Runtime 能力

系统单独封装 Agent Runtime 模块，用于统一承载 AI Agent 能力。

核心方向：

- 接入 AgentScope 最新版本。
- 支持动态挂载 MCP。
- 支持动态挂载 Skills。
- 支持提示词注入。
- 支持按业务场景创建不同 Agent，例如线索分析 Agent、客户总结 Agent、商机推进 Agent。
- 后续支持 Agent 执行记录、调试、审批和安全控制。

### 9. 知识库与工作流

后续会把产品资料、行业方案、销售话术、成功案例和合同模板沉淀到知识库。

规划能力：

- 知识文档管理。
- RAG 检索增强。
- 销售话术生成。
- 客户问答辅助。
- 跟进任务自动生成。
- 关键业务流程编排。

### 10. 日志与可观测性

系统需要具备企业级运维基础。

规划能力：

- 登录日志。
- 请求日志。
- 操作审计。
- 异常日志。
- AI 调用日志。
- 日志文件落盘。
- 后续支持日志检索、告警和调用链追踪。

## 四、产品闭环

产品核心闭环如下：

1. 市场渠道产生录音、视频、表单、活动名单等原始信息。
2. 渠道管理统一接收并结构化存储。
3. 中文转译和 AI 分析提取联系人、公司、需求、预算、意向、风险。
4. 有价值渠道记录晋升为线索。
5. 销售跟进线索并转化为客户或商机。
6. 客户经营过程中持续沉淀互动记录、需求变化和决策链信息。
7. AI 基于真实数据生成客户摘要、商机建议和风险预警。
8. 管理层通过仪表盘查看业务进展、团队效率和转化质量。

## 五、当前建设原则

- 不构造虚假业务数据。
- 页面没有真实数据时展示空状态。
- 后端权限必须兜底，前端只做交互辅助。
- 超级管理员只能有一个。
- 权限编码、菜单编码、角色编码由后台自动生成。
- 接口优先使用 POST，便于统一参数、安全和审计。
- 后端使用 DDD 分层组织。
- Java Bean 使用传统 `@Autowired` 字段注入。
- Java 注释如需出现，统一使用中文。

## 六、迭代计划

### 第 1 阶段：基础可用版

目标：让系统具备可登录、可初始化、可管理组织权限、可进入核心业务模块的基础能力。

周期建议：1-2 周。

交付内容：

- 系统初始化安装。
- 唯一超级管理员。
- 登录、JWT、Redis 分布式会话。
- 用户管理。
- 部门管理。
- 角色管理。
- 菜单权限。
- 数据权限。
- 前端统一布局、主题、Logo、环境配置。
- 客户列表与详情真实接入。
- 基础日志落盘。

验收标准：

- 新环境启动后可以完成首次初始化。
- 登录后根据权限展示菜单。
- 不同数据权限用户看到的数据范围不同。
- 客户列表来自真实数据库。
- 没有数据时不显示模拟数据。

### 第 2 阶段：CRM 核心业务版

目标：补齐传统 CRM 的主链路，让业务数据真正流转起来。

周期建议：2-3 周。

交付内容：

- 线索管理完善。
- 客户管理完善。
- 商机管理完善。
- 跟进记录管理。
- 销售任务管理。
- 渠道记录晋升线索。
- 客户与线索、商机、跟进记录关联。
- 基础仪表盘统计真实业务数据。

验收标准：

- 渠道可以创建线索。
- 线索可以转客户或商机。
- 客户详情能看到关联业务数据。
- 销售负责人能查看团队业务进展。

### 第 3 阶段：AI 能力接入版

目标：把 AI 从“预留入口”升级为可真实使用的业务辅助能力。

周期建议：3-4 周。

交付内容：

- 大模型配置管理完善。
- Agent Runtime 接入 AgentScope。
- MCP 动态挂载。
- Skills 动态挂载。
- 提示词模板管理。
- 录音/视频中文转译接入。
- 渠道内容 AI 分析。
- 线索意向评分。
- 客户摘要生成。
- 商机下一步建议。

验收标准：

- 管理员可以配置模型。
- 渠道音视频可以进入转译流程。
- AI 分析结果落库并可追溯。
- 销售能基于客户真实数据查看 AI 摘要和建议。

### 第 4 阶段：营销增长版

目标：从管理工具升级为营销增长工具，帮助企业判断渠道质量和销售策略。

周期建议：3-4 周。

交付内容：

- 渠道 ROI 分析。
- 线索来源质量分析。
- 重复线索识别。
- 客户分层。
- 客户风险预警。
- 商机赢单率预测。
- 销售跟进节奏建议。
- 邮件、话术、方案内容生成。
- 知识库 RAG 接入。

验收标准：

- 可以看到不同渠道带来的线索量、转化率和客户价值。
- AI 能给出客户跟进建议，并能追溯依据。
- 销售团队可以复用知识库生成话术和方案。

### 第 5 阶段：企业级增强版

目标：提升系统稳定性、安全性、扩展性和企业级交付能力。

周期建议：长期持续迭代。

交付内容：

- 操作审计。
- AI 调用审计。
- 成本统计。
- 模型调用限流。
- 多租户隔离增强。
- 数据导入导出。
- 数据备份与恢复。
- 权限模板。
- 审批流。
- 开放 API。
- 第三方系统集成，例如企微、钉钉、飞书、呼叫中心、邮件系统。

验收标准：

- 系统具备企业内部正式部署能力。
- 关键操作可审计。
- AI 调用可控、可查、可追踪成本。
- 可以和企业现有销售及办公系统打通。

## 七、建议优先级

短期优先级：

1. 组织、用户、角色、菜单权限、数据权限稳定。
2. 客户、线索、商机三大核心数据模型打通。
3. 渠道晋升线索闭环跑通。
4. 大模型配置和 Agent Runtime 基础能力跑通。

中期优先级：

1. 音视频转译。
2. AI 分析结果落库。
3. 客户摘要与线索评分。
4. 真实业务仪表盘。

长期优先级：

1. 知识库 RAG。
2. 商机预测。
3. 销售自动化工作流。
4. 多渠道集成。
5. 企业级审计与成本治理。

## 八、主要风险与依赖

- AI 效果依赖真实业务数据质量，需要尽早定义数据录入规范。
- 音视频转译需要确定供应商、成本和私有化要求。
- 大模型调用涉及密钥、成本、审计和安全策略，不能只做前端配置。
- 数据权限必须以后端强校验为准，前端隐藏只能作为体验优化。
- 渠道、线索、客户、商机之间的状态流转规则需要业务负责人确认。
- 如果要做企业级部署，需要提前确定 PostgreSQL、Redis、MinIO、Elasticsearch、Nacos 等基础设施方案。

## 九、管理层可以关注的阶段性指标

- 渠道记录数。
- 渠道晋升线索数。
- 线索有效率。
- 线索转客户率。
- 客户新增数。
- 商机新增数。
- 商机赢单率。
- 销售跟进及时率。
- AI 分析覆盖率。
- AI 建议采纳率。
- 单条线索处理成本。
- 不同渠道的投入产出比。

## 十、总结

智能营销管理系统的建设方向是：先把企业营销和销售的真实业务数据沉淀下来，再通过权限、流程、AI 和数据分析逐步提升销售效率。短期先完成传统 CRM 必备能力和权限体系，中期打通渠道到线索、客户、商机的业务闭环，长期通过 Agent、MCP、Skills、知识库和工作流形成真正可落地的 AI CRM 平台。
