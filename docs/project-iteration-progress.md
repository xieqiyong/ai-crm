## 五、维护规则

1. 每次开始开发前先新增任务，状态设置为“待开始”或“进行中”。
2. 功能代码完成但尚未经过业务测试时，统一标记为“待验收”，不能直接标记为“已完成”。
3. 用户确认功能可用或集中回归通过后，再填写完成日期并改为“已完成”。
4. 暂时不继续开发但需要保留成果的任务，标记为“已暂停”，不能标记为“已取消”。
5. 任务范围发生变化时，在原任务记录中补充说明；如果属于新的交付目标，应新增迭代编号。
6. 进度表只记录真实完成情况，不使用演示数据或推测结果作为验收依据。
7. 迭代编号格式统一为 `CRM-年月日-序号`，候选任务使用 `PLAN-序号`。
